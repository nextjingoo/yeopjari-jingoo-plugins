# 요약보고서 작성

## 이런 분께 필요합니다

투자 기획서, 사업 기획서, 서비스 제안서처럼 수십 페이지짜리 원본 자료를 임원 보고용으로 짧게 정리해야 하는데, 매번 무엇을 넣고 뺄지 감으로 판단하다 보니 결과물 품질이 들쭉날쭉했던 분.

## 목적

원본 자료를 그대로 요약하는 것이 아니라, **"이 임원에게 지금 왜 이 내용을 전달해야 하는가"**를 먼저 확인한 뒤 그 기준으로 재구성합니다. 같은 원본이라도 보고 대상·목적·형식에 따라 완전히 다른 보고서가 나오도록 설계되어 있습니다.

## 주요 기능

- **원본 자동 파악**: PPTX/DOCX/PDF/이미지 등 형식과 무관하게 원본을 구조화해서 읽어냅니다.
- **9개 항목 인터뷰**: 보고 목적, 임원 성향, 분량, 리스크 포함 여부, 보고 대상, 발표 동반 여부 등 보고서 방향을 결정하는 핵심 질문만 골라 묻습니다. 상황에 따라 자동으로 추가 질문이 열립니다(예: 승인 요청이면 결정 기한을, 고객사 대상이면 경쟁사 언급 범위를).
- **독립 자가검토**: 작성자와 별개의 시각으로 초안을 다시 채점하는 전담 검토 단계가 있어, 스스로 검토할 때 생기는 "내가 쓴 글은 좋아 보인다"는 착시를 걸러줍니다.

## 기능 흐름

```
원본 자료 확인
   ↓
원본 상세 파악 (원본을 빠짐없이 구조화)
   ↓
인터뷰 (9개 항목 + 상황별 추가 질문)
   ↓
보고서 초안 작성 (인터뷰 결과 반영)
   ↓
독립 자가검토 (맞춤화·구조화·명확화·실행화 점검)
```

각 단계 결과는 다음 단계로 넘어가기 전 사용자가 확인할 수 있게 보여줍니다. 인터뷰 답변을 잘못 골랐다면 그 자리에서 바로 수정할 수 있습니다.

## 결과물

- **상세파악 문서**: 원본 내용을 빠짐없이 정리한 중간 산출물 (검증용)
- **보고서 초안**: 인터뷰 결과와 자가검토 기록까지 포함된 완성 문서. Executive Summary → 배경 → 현황 → 대안 비교 → 추천안 → 임팩트 → 실행계획 순서로, 각 섹션 제목부터 핵심 결론이 담긴 형태로 나옵니다.

## 사용자가 얻는 이점

- 매번 처음부터 고민하지 않고, 정해진 질문에 답하는 것만으로 보고서 방향이 잡힙니다.
- 임원 성향·리스크 노출 범위 같은 조건을 놓치지 않아 "이 부분은 왜 안 챙겼냐"는 지적을 줄일 수 있습니다.
- 독립 검토 단계 덕분에 제출 전에 스스로 발견하기 어려운 허점을 미리 잡아냅니다.
