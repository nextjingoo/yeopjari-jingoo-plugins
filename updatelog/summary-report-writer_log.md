# 요약보고서 작성 플러그인 업데이트 로그

플러그인을 설치한 뒤에도 계속 좋아지고 있어요. 이 문서는 무엇이 왜 바뀌었는지 사용자 눈높이에서 정리한 기록입니다. 업데이트 방법은 [UserGuide.md](../UserGuide.md)를 참고하세요.

## v1.0.2 (2026-08-29)

**이런 점이 나아졌습니다**

- 문서 말미의 내부 관리용 표기를 정리했습니다 (기능 변화 없음).

## v1.0.1 (2026-08-29)

**이런 점이 나아졌습니다**

- **선택형 질문 도구가 없는 환경에서도 인터뷰가 끊기지 않습니다.** 일부 환경에서는 버튼으로 답을 고르는 선택형 질문 기능이 없을 수 있는데, 이런 경우 번호가 매겨진 보기 목록과 "기타(직접 입력)"로 자동 전환되어 인터뷰가 막히지 않고 끝까지 진행됩니다.
- **설치 환경(Claude Code / Claude Cowork 등)에 따른 안내가 더 정확해졌습니다.** 4단계 자가검토(초안을 직접 점검하는 단계)가 어떤 환경에서 서브에이전트로 자동 수행되고, 어떤 환경에서 메인 에이전트가 직접 수행하는지 안내를 명확히 다듬었습니다.
- 그 외 설명 문구를 다듬어 가독성을 높였습니다 (기능 변화 없음).

## v1.0.0 (2026-08-29) — 최초 배포

투자/사업 기획서 등 수십 페이지 분량의 원본 자료를 임원 보고용 요약 보고서로 재구성하는 표준 프로세스를 플러그인으로 처음 선보였습니다.

- 원본 자료 상세 파악
- 9개 항목 인터뷰(보고 목적·형식·리스크 포함 여부 등)
- 보고서 초안 작성
- 독립 서브에이전트를 통한 자가검토

네 단계를 거쳐 누구나 같은 절차로 일관된 품질의 보고서 초안을 만들 수 있습니다.
